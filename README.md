# Подбор автозапчастей

Клиент для веб-сервиса «Проценка» Favorit Parts ([документация](https://lk.favorit-parts.ru/static/wsprice.pdf)).
Поиск идёт в два этапа: по артикулу находим производителей, затем по выбранному производителю получаем саму деталь и её аналоги с ценами и остатками.

**Стек:** React 19, Redux Toolkit, Tailwind CSS 4, Vite. Без TypeScript.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Ключ покупателя берётся из переменной `VITE_FAVORIT_KEY` (см. `.env.example`).
Если она не задана, используется публичный демо-ключ из документации, так что проект запускается без настройки.

```bash
npm run build    # production-сборка в dist/
npm run lint     # oxlint
```

## Как устроено

```
src/
  api/favorit.js        запросы к API, разбор ошибок, нормализация ответа
  store/searchSlice.js  состояние поиска и два async thunk: fetchBrands, fetchOffers
  components/
    SearchForm.jsx      поле артикула, поиск с задержкой 500 мс после ввода
    BrandList.jsx       этап 1: список производителей
    OffersTable.jsx     этап 2: деталь и аналоги, раскрываются до списка складов
    Loader.jsx, Message.jsx, StockBadge.jsx, icons.jsx
  utils/format.js       форматирование цены и даты
```

### Особенности API, которые учтены

- **Ошибки** приходят с HTTP 403 и телом `{"error": "..."}`. Известные сообщения переводятся на русский, сбой сети и битый JSON обрабатываются отдельно. В каждом случае пользователь видит кнопку «Повторить».
- **«Не найдено»** приходит как массив с одной пустой структурой (`goodsID` из нулей). Такие записи отфильтровываются, и показывается пустое состояние.
- **Цена** берётся из `warehouses[].price`: поле `price` у товара по документации устарело. В списке показывается минимальная цена («от …»), в раскрытой строке все склады с датой отгрузки.
- **Спецсимволы** в бренде и номере (`Meat & Doria`) экранируются через `URLSearchParams`.
- **Номер на втором этапе** берётся у выбранного производителя, а не из поля ввода: он может отличаться (`01089` → `GLASER H01089-00`).
- **Гонки запросов:** если пользователь успел ввести новый артикул или выбрать другой бренд, ответ на устаревший запрос игнорируется (сверка `requestId`).
